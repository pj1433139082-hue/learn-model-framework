# 测点模型从零示例（完全虚构）

从模板创建 `--serving-mode point-code` 的草稿后，在私有工作区填写 `serving` 和测点绑定。某一字段若由平台数采点提供，平台请求中它的值是测点编码字符串数组；模型签名必须与数组类型一致，不能声明为 `double` 后再传数组。真正的控制设定值可为数值；仅用于评估的目标列不应成为在线推理必填。

历史模型还须确认时区、窗口起止、采样完整性、特征转换及缺失处理。时间字段是否必填由该模型契约决定，不从别的模型照搬。取数失败或窗口不完整应按已确认策略处理；生产不能暗中降级到 mock。用虚构点位 `EXAMPLE_FLOW_A` 测模板，真实点位只写私有模型绑定文件。
