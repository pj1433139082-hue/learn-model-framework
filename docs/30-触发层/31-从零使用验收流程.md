# 纯框架从零验收

以没有本项目上下文的新人视角，在干净克隆中先只读 `AGENTS.md`、入口页与 README，按需跟随这些入口的链接；使用初始化助手配置 Python 3.11、`.[test]` 与仓库外临时模型目录。先预览再创建一个虚构草稿，运行 `context/status`，保存并恢复一次显式任务 ID 的交互档位；不访问真实公司数据或平台。

核对技能同步或直接读取来源的后备方式，以及 hook 文件存在不等于客户端已信任。用固定 launcher 从含旧同名模块的目录调用，验证来源仍是当前框架。拉取 `main` 后执行 bootstrap update，验证依赖与技能同步、目录复用、前后提交记录及另建克隆的回退说明，不修改模型契约。无法在当前机器验证的 OS/权限项需逐条标明。

再运行 `test-profile local`、`release-gate`，核对阶段、退出码和是否意外生成仓库内 `models/`。缺真实公司模块时目标档必须明确 BLOCKED，不能被算成通过。记录验证日期、命令、结果与未验证边界；脏工作树试用与干净克隆验收要分开表述。
