# 公开样板模型分发与三层部署验证加速

状态：已接受（2026-10-12）

## 背景

随着北控模型通用框架（`learn-model-framework`）推进开源与团队分发，暴露出两个核心工程体验痛点：
1. **分发仓库缺乏直观感知模型工作区（缺少样板壳子）**：
   此前 ADR 0019 / ADR 0020 为严密保护商业机密与在役资产，对分发库实施了 `models/` 目录的绝对禁止。这导致外部使用者或同事 Clone 分发仓库后，目录树中完全没有 `models/` 文件夹，无法直观建立“标准水处理模型工作区长什么样”的认知，缺乏开箱即测的样板工程；
2. **部署与门禁验证流程耗时过长**：
   在 Windows 开发控制面与 WSL Linux 生产目标双运行时架构下，每次实包打包（`bundle-build`）均在 Windows 挂载盘（`/mnt/e/...`）创建临时目录，引发严重的 9p/drvfs 跨盘 I/O 延迟；同时 MLflow 依赖锁定与重型加载、结合 403 项测试的全量回归（~6 分钟）和跨平台回放（~3 分钟），导致日常迭代体验沉重。

为了兼顾“100% 商业隐私安全”与“优秀的开源开箱即用体验”，并从根本上解决部署与验证流程的性能瓶颈，制定本决策。

## 决策

1. **确立公开样板模型（Sample Model Workspace）与精细化隐私放行边界**：
   - 在框架中提供一个完全脱敏、纯合成数据、业务逻辑为标准前馈投药计算的样板模型工程 `models/sample-water-model`，具备完整的契约清单（`model.yaml`）、数据绑定（`input-bindings.yaml`）、设计规格（`model-spec.md`）、决策记录（`decisions.yaml`）、纯净源码（`src/model.py`）、单元测试（`tests/test_model.py`）与离线评估报告（`validation/validation-report.md`）；
   - 改造脱敏分发引擎（`model_lab/distribution.py`）：打破对 `models/` 的全局黑名单限制，转为**精确放行白名单**——仅允许导出 `models/sample-water-model` 与框架专用的 `models/README.md`，严密拦截 8 个真实商业资产（`01_*` ~ `08_*`）及一切真实业务草稿（`_drafts/*`）；
   - 分发仓库的发布门禁（`release_gate.py`）同步升级，允许 `sample-water-model` 路径存在，同时对真实厂站编号（`PS[0-9]{4}`）、内部实验编号、私有路径及二进制 `.pkl` 保持零容忍拦截。
   - 主仓库的中央资产目录生成器（`model_lab/catalog.py`）明确将 `sample*` / `template*` / `_*` 排除在在役资产统计之外，确保 8 在役模型盘点与全量回归保持严格不变。

2. **落地三层部署与验证加速架构（Three-Tier Acceleration Strategy）**：
   - **层级 1：日常研发环（毫秒级反馈）**：
     规范开发准则：日常算法迭代与参数调试严格限制在模型私有单测（`python -m unittest tests/test_model.py`，耗时 < 0.3s），配合 `model-lab doctor` 与契约元数据检查（< 3s），日常禁止触发全仓测试与 WSL 打包；
   - **层级 2：实包构建与 WSL 跨盘 I/O 加速（提升 3~5 倍）**：
     重构 `bundle-build` 暂存机制，支持环境变量 `MODEL_LAB_BUILD_TEMP_DIR`（在 Linux/WSL 环境中默认使用原生 `/tmp` 或内存 tmpfs），彻底避开 9p/drvfs 挂载盘 I/O 泥潭；在构建完成后通过 `shutil.move` / cross-device 机制将成品单次安全移入仓库 `release-bundle/service`；
   - **层级 3：预检与全量门禁按需卡点（抽样加速与阶段分流）**：
     日常开发提供轻量预检与单样本签名核验；48 周期多时序高精回放与全仓 403 项测试仅在终审合入主干（PR 阶段）及正式向平台发布（`publish --apply`）前作为终极质量卡点。

## 影响

- **收益**：
  - `learn-model-framework` 具备开箱即用的标准样板模型，使用者 Clone 后即可立即运行测试并体验一键打包；
  - 彻底打通 WSL 构建的 I/O 瓶颈，MLflow 打包预检提速显著；日常研发实现毫秒级快速反馈。
- **安全与兼容性保证**：
  - 8 个真实在役商业模型的源码、权重和测点信息保持 100% 物理隔离，不漏出一行；
  - 主仓库的现有四道硬门禁、测试套件与在役资产目录保持 100% 绿灯。
