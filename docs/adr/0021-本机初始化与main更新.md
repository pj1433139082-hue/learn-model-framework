# 本机初始化与 main 更新

状态：已接受（2026-10-01）

用户选择一次本机初始化助手并保留手工后备，同事默认克隆、拉取 `main`；不要求用户选择稳定标签。初始化记录外部私有目录并检查 Python 3.11、实际框架来源与项目技能；hook 是否信任由客户端处理，未启用时可按入口与 CLI 完整使用。

更新按 `git pull --ff-only` 后同步依赖与技能执行，记录旧/新框架提交，模型任务保留实际使用的框架版本/提交。框架更新不自动迁移模型契约或覆盖模型证据；异常时按已记录提交回退本机工具。这样保留同事直接使用 main 的习惯，同时让问题可追溯；任务档位恢复和已交办步骤不再触发重复确认。
