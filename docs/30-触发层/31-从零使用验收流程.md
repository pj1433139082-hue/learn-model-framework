# 纯框架从零验收

以没有本项目上下文的新人视角，在干净克隆中只读 `AGENTS.md`、入口页与 README；用 Python 3.11 安装 `.[test]`，把 `MODEL_LAB_MODELS_ROOT` 指向仓库外临时目录。先预览再创建一个虚构草稿，运行 `context/status`；不访问真实公司数据或平台。

再运行 `test-profile local`、`release-gate`，核对阶段、退出码和是否意外生成仓库内 `models/`。缺真实公司模块时目标档必须明确 BLOCKED，不能被算成通过。记录验证日期、命令、结果与未验证边界；脏工作树试用与干净克隆验收要分开表述。
