# Triage Labels

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者尚未评估 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可由智能体实施 |
| `ready-for-human` | `ready-for-human` | 需要人员操作或决策 |
| `wontfix` | `wontfix` | 明确不实施 |

技能提及规范角色时，使用表中对应的 GitHub 标签。
