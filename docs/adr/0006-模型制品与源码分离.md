# 模型制品与源码分离

状态：已接受（2026-09-16；状态行补记于 2026-10-10）

后续修订（2026-10-10）：制品摘要在清单中的实际作用是**登记**而非磁盘校验——校验只确认其为规范 SHA-256 格式，从不把 URI 解析到本地文件；模型制品全部被忽略规则排除在 Git 之外，构建流程自行生成服务包内的制品，不读取模型目录下的制品文件。因此“在使用制品前校验完整性与来源”由发布链路的制品预检与远端回载核验承担，不由清单摘要与本地文件的比对承担；文档不得暗示该摘要锁定本地文件。见 [ADR 0020](./0020-历史审计证据由归档分支保存.md)。

模型权重、大型数据、序列化对象和原生运行库不进入普通 Git 历史，而存放在受控制品服务中；Git 只保存其 URI、摘要、来源和兼容信息，小型脱敏测试夹具除外。该边界降低仓库复制与审计成本，但要求模型资产清单和验证流程在使用制品前校验完整性与来源。
