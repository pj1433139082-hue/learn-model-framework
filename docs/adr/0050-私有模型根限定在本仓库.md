# 0050 私有模型根限定在本仓库 models

- 状态：私有源仓专属，不适用于本框架分发仓
- 日期：2026-10-20

> 本仓是公开框架分发仓，私有模型根必须在仓库外；`models`、`models/_drafts` 等仓库内路径
> 会被 `models_root_inside_framework` 拒绝（见 `AGENTS.md` 与 `tests/test_framework_flow.py`）。
> 本文件保留编号与私有源仓决策背景，不作为本仓操作指南。
