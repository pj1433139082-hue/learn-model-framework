# 触发层说明（30）

读这一层是为了知道「上线前必须过哪些检查、怎么算过」。

## 放什么
- 上线前检查清单：逐条可勾选，一条一个判据。
- 从零使用验收流程：新环境落地时要走的验证顺序。

## 不放什么
- 规则本身（阈值、口径） → `20-规则层`。
- 某一次验收的过程、截图、结论 → `90-归档`（本层只留仍要执行的清单）。
- 一次性的复核记录：同一主题已结束就整篇移入 `90-归档`，不在本层留摘要。

## 编号与命名
`<NN>-<主题>.md`，两位数字；同层不重复编号。检查清单与验收流程各占一个号，不再追加同类页。

## 剥离说明
- 历史特定模型的冷启动记录与真实水厂验收差距属于内部审计证据，已按规范剥离，不在公开分发范围内。
