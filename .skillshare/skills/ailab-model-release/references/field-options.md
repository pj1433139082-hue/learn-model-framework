# 表单字段与下拉实录

2026-10-28 在平台页面逐项点开的实录。平台会加项，脚本一律按**文本**匹配，不要按下标。

## 表单结构

新建模型与另存为新版本共用同一套表单，分三段：

1. **模型信息**：名称、类型、分类、版本别名、编程语言、适用场景、描述、数据分类等；
2. **绑定部署文件**：当前关联部署 + 「切换部署文件」；
3. **参数配置**：输入参数表 / 输出参数表 + 「同步输入输出参数」。

## 必填 7 项

| 字段 | 控件 | 脚本可填 | 说明 |
|---|---|---|---|
| 模型名称 | 文本 | 是 | 列表里的显示名；搜索用的是模型编号或名称片段 |
| 模型类型 | `el-select` | **否** | 见下方「模型类型」；popper 脚本抓不到，人工点 |
| 分类 | `el-select` | **否** | 随模型类型变化；人工点 |
| 版本别名 | 文本 | 是 | 版本的可读名，如 `0.2.0` |
| 编程语言 | 文本 / 下拉 | 是 | 如 `Python` |
| 模型适用场景 | `el-select` | 是 | 同页可脚本选中 |
| 模型描述 | 多行文本 | 是 | 写清输入契约与用途 |

保存按钮灰 = 这 7 项里有空的；`ailab-new-model.mjs` 会列出仍为空的必填项。

## 下拉选项实录

| 字段 | 选项 | 备注 |
|---|---|---|
| 模型类型 | `算法` / `智能体` / `数据规则模型` | 选「算法」才出现下面的分类 |
| 分类（算法） | `回归` / `分类` / `排序` / `时序序列` | 时序类模型选「时序序列」 |
| 数据分类 | `默认分类` / `污水` / `供水` / `厂网`（+ 创建新子主题） | 按需，不阻塞保存 |
| 模型适用场景 | `无特定场景` / `污水处理工艺` / `A2O工艺` / `氧化沟工艺` / `SBR工艺` / `MBR膜工艺` / `污水处理设备` / `曝气风机` / `DO溶解氧仪` / `污泥回流泵` … | 列表会随平台扩充，按文本找 |
| 计算资源 | `CPU` / `GPU` | 按需；默认 CPU |
| 模型开放范围 | 平台内选项（按需） | 不阻塞保存 |
| 标签 | 自由输入 | 不阻塞保存 |

## 状态取值

列表两列，各自三值，且列表顶部有同名筛选：

| 列 | 取值 |
|---|---|
| 发布状态 | `已发布` / `发布审批中` / `未发布` |
| 部署状态 | `已部署` / `部署审批中` / `未部署` |

版本管理弹窗里每行还有 `查看` / `另存为新版本` / `取消发布`，弹窗顶部是 `版本更新`。

## 版本号规则

- 「另存为新版本」自动填上一版 +1：`V001` → `V002`；列表按版本号排序。
- 「版本更新」不改版本号，只改这一版的部署文件与参数。
- 覆盖前先确认新版本号没被占用（别的同事可能已经建过）。

## 参数表里的类型

「同步输入输出参数」之后，参数表会显示每个参数的名称与类型：

| 类型显示 | 含义 | 备注 |
|---|---|---|
| `string` | 单个字符串 | `factory_code`、`start_time` 都是 |
| `array` / `array<string>` | 字符串数组 | 测点编码数组应为 16 个（风机效率 2619） |
| `double` | 浮点数 | 输出列正常；**输入列出现就是签名不干净** |
| `any` | 未推断出类型 | 不应该出现，出现就回模型侧改签名 |

## 其余按需字段

业务分析主题 / 子主题 / 数据分类下的自定义子主题、模型开放范围、标签都属于「按需」，不影响保存；先跑通必填 7 项，再回来补。
