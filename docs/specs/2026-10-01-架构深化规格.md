## 范围与不变式

只修改纯框架。Python 3.11、外部私有模型目录、原有目标平台和摘要固定规则不变；不读取或迁移真实模型，不引入审批、历史重写或远端操作。只对真实已完成的操作报告完成，不能把发生写入但未核验的远端状态说成发布成功。

### 1. 路径祖先检查

现有 `path_safety` module 公开一个小 interface：按原始路径顺序查找首个链接或 junction，含末端及已存在祖先。检查经过 `..` 前的路径，不先 `resolve()` 隐藏链接。调用者保留路径角色、框架内外、本地/网络磁盘、异常分类与调用时机；不得减少写入前已有检查。

### 2. ZIP 精确读取

共享的受限读取 module 从同一份有界文件内容读取目标成员；ZIP 总大小上限 16 MiB，目标成员上限 2 MiB；全包重复名称、缺失目标成员和目录目标成员被拒绝。实际读取也有上限，不仅相信 ZIP 元数据。不开目录、不解压到磁盘、不导入代码、不联网。

doctor 保留外部路径与 Windows/Linux 静态格式检查，文件已检查不代表固定摘要验收。构建保留当前 Linux x86_64 契约及整包/成员固定摘要；两条入口继续使用各自错误分类。bootstrap 平台 adapter 不合并到需要已安装 Python 的入口。

### 3. 已完成操作的记录恢复

`new/maintain/draft-fork/advance` 的事实完成后，以及指定 Run 已回载核验后的 `publish/verify-publication`，索引写入 I/O 失败最多补写一次。每次调用完整索引写入 interface，重新执行路径与事实校验；不重试不安全路径或无效事实，不自动补写回执，不重做创建、推进、上传或回滚。

索引流写入失败与替换失败均须清理本次创建的临时文件，不删除清单、原索引或回执；不以恢复为理由改变既有原子替换语义。

普通成功的 JSON 字段保持不变。实际发生索引恢复，或记录仍不完整时，追加：

```json
{
  "completion": {
    "operation": "completed",
    "local_record": "incomplete",
    "repeat_operation": false
  },
  "local_record": {
    "failed_part": "snapshot",
    "snapshot_attempts": 2,
    "error_type": "OSError"
  },
  "recovery": {
    "action": "refresh_snapshot",
    "command": ["bash", "<framework>/scripts/model-lab.sh", "context", "<workspace>", "--write", "--format", "json"],
    "remote_writes": false
  }
}
```

`local_record` 为 `complete` 或 `incomplete`；成功补写后的 `failed_part/error_type` 为 null，`recovery.action` 为 `none` 且命令为空。命令是参数列表，固定使用实际加载的框架绝对启动器，不依赖 PATH 上的旧 `model-lab`。上例为 Linux；Windows 使用 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File <绝对路径>/scripts/model-lab.ps1`，Bypass 仅适用于该子进程，不修改系统策略。含路径时不得自行拼接为未经引用的 shell 执行字符串；Windows 人类文本使用 PowerShell 字面量引用。

回执失败时 `failed_part=receipt`、`snapshot_attempts=0`，恢复动作是 `verify_existing_publication`，指向同一模型、实验和 Run 的 `verify-publication` 命令。存在冲突或不安全回执时保留明确原因，不覆盖、删除或伪造回执。

远端已核验而本地记录失败时，保持 `published` 或 `verified`，并追加记录结果与恢复指引。CLI 的记录不完整退出码为 2；正常成功或成功补写为 0。操作前拒绝与远端核验失败的既有失败分类保持。中文输出明确“操作已完成，但本地记录不完整”，不能提示重复原操作。

## 验收

- 路径：公开 CLI 写入入口拒绝祖先链接、junction、原路径含 `..` 等危险路径，验证无副作用；合法外部目录与未创建末端仍可用。
- ZIP：公开 doctor 与 bundle-build 预览使用合成包覆盖正常、重复无关成员、缺成员、目录、超限、损坏、平台头错误与固定摘要差异；无解压/导入/联网。
- 恢复：公开 CLI 创建/分叉/推进和发布/核验 interface，注入外部文件系统、MLflow SDK 故障；验证单次恢复、持续故障、事实提交前失败、回执失败与冲突，解析 JSON 和安全后续操作。不能用内部 helper 替身伪造成功。
- 保留现有原子写入与竞争保护测试；最后执行 doctor、local 测试档、release-gate 和独立对抗性审查。
- Windows 和 Linux 结果分别记录；权限不足或运行环境缺失的跳过/未运行不得计为通过。通用框架验收不等于真实模型上线。
