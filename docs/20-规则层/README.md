# 规则层说明（20）

读这一层是为了知道「哪些线不能踩、参数按什么口径填」。本层每条都应是**可判定**的：写规则，不写故事。

## 放什么
- 硬性规则速查：一条一句，带违反后果与出处。
- 参数与配置口径：字段含义、单位、取值边界、可复制的 JSON 速查。
- 数据与字段映射：数据集、字段角色、时间口径。
- 模型专属约定：阈值、窗口、状态枚举等需要长期固定的取值。

## 不放什么
- 操作步骤与阶段交付物 → `10-流程层`。
- 某次结果、验收经过、截图与时间线 → `30-触发层` 或 `90-归档`。
- 已被取代的旧规则 → 改写现行条目，并在 `90-归档` 留历史原文。

## 编号与命名
`<NN>-<主题>.md`，两位数字；同层不重复编号。跨层撞号允许（各层独立编号空间），但同层内必须唯一。

## 剥离说明
- 具体水厂、测点与平台的私有参数配置不随通用框架分发，已按安全准则剥离；本层保留的是通用口径与字段规范。
