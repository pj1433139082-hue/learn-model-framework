# 入口层说明（00）

读这一层是为了知道「这套框架怎么用、我现在该走哪条路」。它是入口，不是规定。

## 放什么
- 总览与分流：工作流六阶段（0 自检→5 发布，不同于资产状态七态）、命令清单、任务分流与最小加载矩阵。
- 首次使用指引：从零示例、人工操作快速开始、交互档位约定。
- 状态快照：每轮注入的上下文与 Hook 机制。
- 上线前核对清单：该过哪几关（清单本身，不是某次发布的结论）。

## 不放什么
- 逐步操作手册、阶段交付物要求 → `10-流程层`。
- 不可违反的硬规则与参数口径 → `20-规则层`。
- 某次验收、复核、迁移的具体经过 → `30-触发层`（近期）或 `90-归档`（历史）。

## 编号与命名
`<NN>-<主题>.md`，两位数字；同层不重复编号。子目录只允许 `diagrams/`，且只放图示文件。

## 剥离说明
- 原私有文档 `01-在役模型资产目录.md` 包含公司特定在役模型部署台账，属于私有业务资产，已按旧新分离规范剥离，不进入公开分发框架。
