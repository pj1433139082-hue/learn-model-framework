# 流程层说明（10）

读这一层是为了知道「这件事按什么顺序做、每一步交什么」。

## 放什么
- 端到端 SOP 与各阶段交付物要求（读它就能照着做）。
- 运行与制品契约：Python 3.11、MLflow 制品、在线验收回执口径。
- 发布通道路径选择、取数与网络前置条件。
- 现场数据接入流程：从 `raw/` 到 `delivery/` 的口径与目录骨架（[26](./26-现场数据接入流程.md)）。
- 取数与网络前置：[24](./24-无VPN取数与公网路径验证手册.md)。
- 发布通道选择：[27](./27-模型发布路径选择与集团部署技能包.md)。

## 不放什么
- 单点的阈值、参数取值、字段口径 → `20-规则层`（本层只引用，不复写）。
- 某次部署、验收、故障的时间与人 → `30-触发层`（近期）或 `90-归档`（历史）。
- 可复制的配置 JSON 样例 → `20-规则层` 的速查页。

## 编号与命名
`<NN>-<主题>.md`，两位数字；同层不重复编号，不复用已删除的号。
