# 归档说明（90）

读这一层是为了追溯「当时为什么这么定」。只读不执行：本层不放仍在生效的流程与规则。

## 放什么
- 已结束代次的参数确认记录、迁移说明、冻结或退役记录。
- 被后续 ADR 取代的历史规定（原文保留，并在开头标明被谁取代）。
- 一次性的验收与复核证据：需要长期留档、但不再参与日常执行的那部分。

## 不放什么
- 仍在生效的规则 → `20-规则层`；仍在执行的流程 → `10-流程层`。
- 每次发布都要重读的清单 → `30-触发层`。
- 可执行脚本、数据文件、制品 → 归档分支或对应模型工作区。

## 编号与命名
沿用搬入时的原编号与文件名，**不改名**：外部引用、摘要登记、发布回执都按路径钉住，改名等于断链。
