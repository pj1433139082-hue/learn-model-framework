# 任务分流与最小加载

| 场景 | 技能 | 先看什么 |
| --- | --- | --- |
| 新模型或业务逻辑待定 | `model-requirements-grill` | 目标工作区 `model.yaml`、`decisions.yaml`、需求 SOP |
| 测点、历史窗口、缺失异常 | `model-data-audit` | 该模型绑定与数据质量证据 |
| 源码、Notebook、回归或图表 | `model-build-validate` | 契约、基线、验证报告 |
| Python、MLflow 包、发布准备 | `model-runtime-release` | 运行环境 SOP、`doctor`、`bundle-preflight` |
| 已发布模型改动 | `model-maintenance` | 旧版本真实 Run、基线、待改差异 |
| 仅调整本框架 | `model-lab-router` | 本页、交互档位、从零验收流程 |

对已有模型用 `model-lab context <工作区> --task <new|maintain|build|publish|status>` 获取实际文档指针。私有模型目录不在本仓库内，找不到时先确认目录或 ID/版本，不猜。
