# 架构决策记录 (ADR)

本目录记录北控模型实验室通用算法框架的系统级技术架构决策。编号以权威源保持严格一致。

## 放什么
- 一条决策一个文件：背景、决策、后果、被否决的方案。
- 只写**不可逆或高代价**的选择（选错了要回滚大量工作），不写日常实现细节。
- 决策被推翻时，新增一条 ADR 说明取代关系，旧条目不删不改。

## 不放什么
- 操作步骤、教程 → `10-流程层`；可判定的阈值与口径 → `20-规则层`。
- 一次性的讨论过程、会议结论、实验数据 → `30-触发层` 或 `90-归档`。
- 只影响单个模型内部实现的取舍 → 写进该模型的 `model-spec.md`。

## 编号与命名
`<NNNN>-<决策一句话>.md`，四位数字连续递增，不复用、不改号；被取代的条目在开头加「被 ADR XXXX 取代」。

## 决策记录索引与收敛

- **ADR 0001~0010, 0012, 0014~0017, 0019, 0021, 0022**: 通用框架契约、模型脚手架、生命周期、安全分叉与记录恢复决策。
- **缺失决策记录说明（0011, 0013, 0018, 0020）**:
  根据旧新分离与隐私安全规范，ADR 0011（平台正式名称归档）、0013（测点特征分层）、0018（状态快照与Hook）、0020（历史审计分支）涉及私有在役模型特定资产命名与测点信息，已按准则剥离。如需查阅请向内部私有仓库负责人索取完整版。
- **ADR 0046~0047**: 分发仓库文档正文回归本仓单一来源、仓库根常驻文件单一来源。
- **ADR 0048~0049**: 守卫边界契约、_drafts 出口判据。
- **ADR 0050**: 私有模型根限定在本仓库 `models`（取代早先「仓库外私有根」的口径）。
- **ADR 0051**: 否决带向量检索的跨会话记忆（召回泄漏不可审计）。
- **ADR 0052**: 步骤台账（`workflow-ledger.json`）只做声称层，verdict 由 `step-check` 重算，本轮只 advisory。
- **ADR 0053**: 子智能体协作契约：写作用域、机器回执、证据 locator、cwd 纪律。
- **ADR 0054**: 敏感事实目录：敏感正则与处置只写一份，按 scope 取规则。
- **ADR 0055**: 仓库检查器单一入口：四个 `scripts/check_*.py` 变薄壳。
- **ADR 0056**: 交付定级三分：blocking / historical / pending，`--strict` 才把历史缺口算失败。
- **ADR 0057**: 决定关闭口径唯一：`answered` 不是关闭态，`confirmed` / `superseded` 才算。
- **ADR 0058**: 工作流选择单一来源：`workflow.id` 优先，模板表只作回退。
- **ADR 0059~0061**: 敏感事实容器扫描与文本判定、镜像计划单一内核、命令注册表与领域错误映射。
