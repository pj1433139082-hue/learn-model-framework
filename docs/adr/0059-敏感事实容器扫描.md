# ADR 0059：敏感事实容器扫描与文本判定

- 状态：已接受（2026-10-21）
- 相关：ADR 0054（敏感事实目录）、`model_lab/privacy.py`、`scripts/export-model-repo.py`

## 背景

ADR 0054 把敏感正则与处置收进一个目录，但留下三个已实测的洞：

1. **容器是盲区**。公开导出只按普通文件读字节，`.docx`/`.xlsx`/`.zip` 里的正文根本没被扫过；分发侧也只把容器当二进制跳过。敏感事实藏在 Office 文档里时，两侧都看不见。
2. **文本判定只看前 8KB**。8KB 之后才出现的 NUL，或截断落在多字节字符中间，都会把二进制误判成文本（或反过来），进而让“改写”打在错误的对象上。
3. **厂站名与厂站码是两套写法**。分发侧只认厂站码，公开导出侧另有一份厂站名词表；同一个事实两处维护，相邻厂站名还会被拆成两次命中。

## 决策

1. **厂站名规则合一**：`plant_code_or_name` 一个正则同时匹配厂站代号与厂站名（含相邻组合写法，整体只命中一次）。`distribution` 仍保持 11 条规则名不变；`export-public` 不再有独立厂站名规则，改用 `ScopeOverride` 把同一条规则解析为 `rewrite`、替换成 `<plant-name>`。规则对象按 scope 解析，调用方拿到的是解析后的副本，正则对象仍与目录同源。
2. **`scan_path(path, rules)` 扫完整文件**：普通文件读全量字节；`.zip`/`.docx`/`.xlsx`/`.pptx` 逐个非目录成员解压扫描，命中带成员名 `location`（`rel:member` 形式由调用方拼）。只解一层，不递归嵌套容器。
3. **容器损坏不静默**：打不开、加密或读取失败时返回一条 `rule == "container-unreadable"` 的 finding（`location` 为文件名），不抛异常也不返回空元组；调用方必须把它当“没扫成”处理。
4. **`is_text_path(path)` 按完整内容判定**：出现 NUL 即二进制，能按 UTF-8 完整解码即文本，不再看前 8KB。公开导出用它决定哪些文件进入改写路径，后缀不再参与判断。
5. **公开导出接线**：`scripts/export-model-repo.py` 的 `_rewrite_public` 只对 `rewrite` 规则改写；`scan_secrets` 对所有 manifest 文件调用 `scan_path`，容器命中按 `rel:member` 报告。改写后再扫一遍，仍有 `block` 级命中就中止。
6. **公开导出的改写面补齐**：`export-public` scope 复用 `user_path`（按 scope 覆盖为 `rewrite`，替换成 `<user-path>`），并新增 `private-repo` 规则（`github.com/<owner>/learn-model[-framework]` 替换成 `<private-repo>`）。两条都只在公开导出生效，分发侧的 `user_path` 仍是 `block`。

## 后果

- Office 与压缩包里的敏感事实不再因为“是二进制”而绕过扫描；损坏容器会显式暴露，不会假装干净。
- 文本判定与后缀解耦，`.js`、`.ts`、无后缀脚本都能被正确改写；8KB 边界的两类误判消失。
- 公开导出不再把本机带用户名的路径和私有仓 owner slug 带出去；实测 `model-eval-scorer` 公开导出 61 文件、`14331` / `pj1433139082-hue` 均 0 命中。
- 厂站名只需维护一处，分发拒绝与公开改写共用同一个正则。
- 代价：容器要整包读入内存后再逐成员扫描，超大压缩包会抬高内存峰值；每次导出多一遍全量扫描。
- 已知限制：只解一层，嵌套压缩包里的内容仍可能漏；没有压缩炸弹/成员大小上限；加密容器一律按 `container-unreadable` 处理；正则仍是启发式，误报漏报都存在。

## 被否决的方案

- **继续按后缀判断文本**：补一个扩展名只解决眼前一个洞，下一个文本格式还会漏；ADR 0054 已因此实际泄漏过一次。
- **容器只报告不阻断**：分发与导出都需要“这份文件能不能外发”的确定答案，只报告等于把判断留给下一个人。
- **损坏容器返回空元组**：调用方无法区分“扫过且干净”和“根本没扫成”，会把坏文件当安全文件放行。
- **保留导出侧独立厂站名词表**：同一事实两套写法，增删必然漂移，正是 ADR 0054 要消除的结构。
