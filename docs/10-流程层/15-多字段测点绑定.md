# 多字段测点绑定

每个真实点位保存在私有模型版本的绑定文件，不保存在本框架。可记录设施名称、设备名称、数采点位编号、数采信号名称、应有信号、单位、时区及取数窗口；未知信息标为“待核实”，不编造。测点编码数组是平台入参，实际数值由模型按契约从 IoT 接口获取并清洗。数组签名、字段角色与在线请求必须一致。

同一时间窗内的缺失、非数值、负值、跨日、延迟及多点对齐策略按具体模型确认。真实接口失败直接报错，除非该模型有经批准的其他降级策略。评估目标值不因字段名含 `_target` 就自动入推理；后缀仅触发人工核对。旧模型专属公式/基线回放应保留在私有包，通过 `model_lab.baseline_runners` Python entry point 接入；框架不复制公式参数或样本摘要。
